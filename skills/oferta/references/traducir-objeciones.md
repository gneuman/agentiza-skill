# Traducir la respuesta del cliente

La respuesta a una propuesta es el dato mas valioso que existe para arreglarla —
y casi siempre nombra el elemento que falta, sin saberlo. Es feedback gratis del
unico evaluador que importa.

**Regla de lectura: casi nunca es lo que parece.** "Esta caro" casi nunca es el
precio. "Lo tengo que pensar" casi nunca es duda. Son la forma educada de decir
algo mas especifico.

## La tabla

| Lo que dijo el cliente | Lo que casi siempre significa | Palanca a arreglar |
|---|---|---|
| "Esta caro" / "pense algo mas sencillo" | La promesa no justifica el numero. No sobra precio: falta valor percibido | **Promesa** (y de paso, forma de pago) |
| "Necesito entender los alcances" | No puede repetir la promesa. Te esta pidiendo el argumento para defenderte adentro | **Promesa** |
| "No me quedo claro" | Explicaste el metodo, no el resultado | **Promesa** |
| "Lo tengo que ver con [socio/jefe/comite]" | Hay una junta a la que no entras. Sin material, va desarmado | **Bono** (el material con el que te vende) |
| "¿Y si no funciona?" / "¿que pasa si...?" | Riesgo percibido mayor que la recompensa | **Garantia** |
| "Dejame lo pienso" / "te aviso" | No hay razon para decidir hoy. Y pensarlo es gratis | **Urgencia/escasez** |
| "¿Hay algo mas economico?" | La entrada pesa. El total puede estar bien | **Forma de pago** |
| "Ahorita no es el momento" | Timing real, O no hay costo de esperar articulado | **Urgencia** (o es un no honesto) |
| "Mandame mas informacion" | Casi siempre es un no suave. Mas informacion rara vez lo arregla | **Promesa** — o aceptar el no |
| Silencio despues de recibirla | La propuesta no dio un paso siguiente que se pueda dar solo | **Urgencia** + CTA mas chico |

## Como leer una respuesta larga

Casi siempre traen varias objeciones mezcladas. **Aislalas una por una** y mapea
cada una. El patron util: cuando hay 2+ objeciones y una es de promesa, **la de
promesa es la causa** y las demas son sintomas. Nadie regatea el precio de algo
que quiere de verdad.

**Ejemplo real** (respuesta de un director a una propuesta de acompanamiento):

> "necesito entender bien los alcances para justificar ese precio, yo pense algo
> mas sencillo la verdad, pero lo tengo que aterrizar primero con mis socios, y
> ver como integramos a [su persona de sistemas] en esto"

Cuatro objeciones en dos lineas:

1. "entender los alcances para justificar" → **promesa** (no la puede repetir)
2. "pense algo mas sencillo" → **forma de pago** (la entrada pesa)
3. "aterrizar con mis socios" → **bono** (va a una junta sin material)
4. "ver como integramos a X" → **bono** (pendiente suyo = razon para posponer)

Causa raiz: la 1. Las otras tres se abarataron solas cuando la promesa se
sostuvo.

## Dos advertencias

**No todo se arregla con oferta.** A veces es un no honesto: no hay presupuesto,
no es prioridad, o no eres tu. Insistir con mas oferta ahi quema la relacion. La
senal: si el cliente **no hace preguntas** sobre el trabajo, no esta evaluando.

**El silencio tambien es dato.** Si no contestan, el problema no es el contenido
de la propuesta — es que no la leyeron completa o no habia un paso siguiente lo
bastante chico. Un CTA que pide "confirmar y arrancar" exige tener todo resuelto
adentro; uno que pide "apartar el lugar" se puede dar desde el telefono.
